# 🔐 CompVault

CompVault is a simple password manager built with HTML, CSS, and JavaScript.

I created this project to learn web development and explore how password managers work behind the scenes. What started as a small experiment gradually evolved into a feature-rich web application with password management, search, import/export functionality, theme switching, and more.

> ⚠️ **Disclaimer:** This project is currently intended for learning and educational purposes. It should not be used to store sensitive real-world passwords until proper encryption and security features are implemented.

---

## ✨ Features

* 🔑 Master password protection
* ➕ Add new passwords
* ✏️ Edit saved passwords
* 🗑️ Delete passwords
* 🔍 Search passwords instantly
* 👁️ Show / Hide passwords
* 📋 Copy passwords to clipboard
* 🎲 Built-in password generator
* 🌙 Dark / Light theme support
* 📤 Export vault to JSON
* 📥 Import vault from JSON
* 💾 Automatic saving using Local Storage

---

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/VedDevs/CompVault.git
```

### Open the project

```bash
cd CompVault
```

### Run the application

Open `index.html` in your browser.

That's it — no installation or setup required.
